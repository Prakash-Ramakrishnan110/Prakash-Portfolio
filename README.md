# Prakash Ramakrishnan - Professional Portfolio

Welcome to the source code for my professional portfolio website! This portfolio highlights my skills, projects, publications, and research in Computer Science, Artificial Intelligence, and Software Engineering.

## 🌐 Live Demo
**[View the Live Portfolio Here](https://prakash-portfolio-alpha.vercel.app/)**

---

## 🚀 Features
* **Modern & Responsive Design**: Built with a clean, dark-themed UI that looks great on desktop, tablet, and mobile devices.
* **SEO Optimized**: Fully integrated with Google Search Console, complete with robust meta tags, `sitemap.xml`, `robots.txt`, and automated JSON-LD structured data for Google indexing.
* **Publications & Research Showcase**: A dedicated section highlighting my published technical books (e.g., *From Code to Innovation*) and academic research papers (e.g., *SearchTrust ML*).
* **Project Gallery**: A clean, grid-based layout showcasing my technical projects and open-source contributions.
* **Fast & Lightweight**: Built with pure HTML, CSS, and vanilla JavaScript without heavy frameworks, ensuring lightning-fast load times.

## 🛠️ Tech Stack
* **Frontend**: HTML5, CSS3, JavaScript (ES6+)
* **Styling**: Bootstrap 4, Custom CSS Animations
* **Icons & Fonts**: Google Fonts (Poppins), DevIcons, FontAwesome
* **Deployment**: Vercel

## 📂 Sections Included
* **About Me**: A summary of my background and professional goals.
* **Resume**: Downloadable PDF resume and timeline of my education and experience.
* **Skills**: A visual representation of my technical competencies.
* **Projects**: Highlighted software engineering and machine learning projects.
* **Books & Research**: Publications including my book *From Code to Innovation* and my research on *SearchTrust ML*.
* **Contact**: Direct links to my professional network and email.
